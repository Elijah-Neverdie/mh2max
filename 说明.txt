mh2max 使用说明（全中文）
========================

版本 1.3.31（Maya 2026 / Max 2026 上开发测试；Maya 2022+ / Max 2022+ 可用）

这是一份给使用者看的说明。GitHub 首页说明见 README.md，版本记录见 更新日志.txt。


一、这个工具做什么
------------------
把 MetaHuman（或已标准化的自定义角色）从 Maya 导出到 3ds Max：

1. 在 Maya 里导入或打开角色
2. 烘焙面部 Morph（单轴 + 二维角落残差）
3. 导出 FBX
4. 启动 3ds Max，自动导入、接线 Morpher、限位、保存场景

Max 是 Z 向上，Maya 是 Y 向上。1.3.31 起由 FBX 在导入时把整棵层级转到 Z 向上（网格、骨骼、控制器、IK、蒙皮一起转），角色应直立站在 Max 里。


二、需要事先准备
----------------
- Autodesk Maya 2022 或更高
- Autodesk 3ds Max 2022 或更高（要导出到 Max 时）
- Epic「MetaHuman for Maya」（要用菜单「导入 MH」时；从 Fab 安装）
- 角色数据：UE 5.6+ DCC Export 的 ZIP/文件夹，或已经装配好的 Maya 场景

本仓库不含约 1.5GB 的 MetaHuman for Maya 压缩包。请到 GitHub Releases 下载
MetaHumanForMaya-1.3.1-win64.zip，放到本仓库 vendor\ 目录。


三、安装
--------
推荐：双击仓库里的 install.bat
- 扫描 Maya / Max，默认全部安装
- 找不到时可以粘贴快捷方式或 3dsmax.exe 路径
- 多个 Max 时可选择默认导出版本
- 配置写在 %LOCALAPPDATA%\mh2max\config.json

手动安装：
1. 把 mh2max.mod.example 复制到
   %USERPROFILE%\Documents\maya\modules\mh2max.mod
2. 编辑该文件，把路径改成你的仓库绝对路径（例如 C:\Users\A\Tools\mh2max）
3. 建议把 userSetup.example.py 里的代码加进
   Documents\maya\scripts\userSetup.py
   （主窗口起来后再装菜单，避免卡在启动屏）
4. 按 Epic 文档安装 MetaHuman for Maya
5. 重启 Maya，顶栏应出现 MH2Max

插件不会再写进 Maya「文件」菜单，以免把系统菜单弄坏。


四、Maya 已经开着，如何刷新菜单（reload_menu.py）
------------------------------------------------
改过插件代码或刚更新仓库后，不必关掉 Maya。

1. Maya 菜单：窗口 → 常规编辑器 → 脚本编辑器
2. 切到 Python 页签
3. 执行（把路径改成你的仓库路径）：

   exec(open(r"C:\Users\A\Tools\mh2max\reload_menu.py", encoding="utf-8").read())

也可以把 reload_menu.py 直接拖进 Python 页签再点执行。

成功标志：
- 脚本编辑器打印 [mh2max] File menu restored ...
- 顶栏 MH2Max 里第一项显示 mh2max v1.3.31

若「文件」菜单只剩 MetaHuman 相关项，同样运行上述脚本即可恢复。


五、菜单说明
------------
MH2Max（或 Epic 的 MetaHuman 菜单内）：

- mh2max v版本号     当前已加载的插件版本（不可点）
- 导入 MH            导入 UE DCC Export（ZIP 或文件夹）并装配
- 检测当前角色       检查场景；非标准角色可标准化
- 导出至 3ds Max     需先检测成功或导入成功
- UE5控制器同步      打开 Maya→UE 控制器同步面板（需本机有对应工程）
- 显示控制器/隐藏控制器  显示或隐藏身体与面部控制器
- 检查更新           查询 GitHub Releases

使用顺序：导入或打开场景 → 检测当前角色 → 导出至 3ds Max。


六、导入 MH
-----------
1. 必须先装好 MetaHuman for Maya
2. MH2Max → 导入 MH → 选 ZIP 或文件夹
3. 文件夹可以是导出根目录，也可以是父目录
   （自动找 ExportManifest.json 或 head.dna + body.dna）
4. 过程目录默认在源旁边：MHI_<名称>\
   已存在则询问覆盖，或自动加 _2 等后缀
5. 装配走 Character Assembler，不能用旧 DHI CharacterImporter 直接装 UE 5.6+ 包

不要同时开两个 Maya。


七、检测与标准化
----------------
检测通过：可以直接导出。

检测失败（自定义角色）：会询问是否标准化。
- 不改原控制器名、骨骼名
- 为面部 FRM + *_Ctrl 建立隐藏的 CTRL_* 代理，供 Max Morph 接线
- 网格映射写入场景；导出任务会带上真实网格短名（如 SM_Male_Head_01）


八、导出至 3ds Max
------------------
Maya 侧：
- 先把全部滑杆归零再烘焙，避免脏姿势污染 Morph
- 导出脸、牙、唾液/牙龈、眼睛等相关网格的 Morph
- 二维控制器每个角落再烘一份残差目标，Max 用双线性权重接线
- FBX 标明 Y 向上，不在 Maya 里先转成 Z 向上

Max 侧：
- 导入 FBX 时轴转换到 Z 向上（整棵根层级一起转）
- Morph OBJ 绕 X 轴转 -90 度，与角色对齐
- 单个 Morpher 接线（通道超过 100 会扩容，避免多层 Morpher 叠坏脸）
- 不给 FACIAL 骨骼写脚本控制器，保护 Skin 绑定
- 按版本保存：{角色}_face_rigged_max{年}.max
  Max 高于 2024 时再尝试一份 _max2024.max

改轴向或 Morph 逻辑后，必须从 Maya 重新点「导出至 3ds Max」。
旧 FBX、旧 .max 不要热修凑合。

导入日志中有 fbx Z-up probe … (standing: Z > Y)
站立角色的包围盒高度应在 Z，而不是躺在 Y 上。


九、轴向要点（1.3.31）
----------------------
Maya = Y 向上，Max = Z 向上。

正确做法：Maya 按 Y 向上写出 FBX，Max 导入时转到 Z 向上。
错误做法：在 Maya 里先把角色转成 Z 向上再导出（会转两次）。

身体控制器目前不在 Max 里重建 Maya 的约束和 IK，以 FBX 层级为准。
面部表情走 Morph，不靠改面部骨骼。


十、常见问题
------------
Q：菜单还是旧版本？
A：运行 reload_menu.py，或重启 Maya。看菜单第一项的版本号。

Q：导出是灰的点不了？
A：先「检测当前角色」成功，或先「导入 MH」成功。

Q：角色在 Max 里躺倒 90 度？
A：确认已是 v1.3.31，并且是重新导出、重新导入的，不是旧 FBX。

Q：Max 里拖 CTRL 没表情？
A：多半没烘到 Morph（自定义网格名未进任务表）。先做标准化再重新导出。

Q：导入 MH 失败？
A：确认已装 MetaHuman for Maya，且用的是 UE 5.6+ DCC Export，不是旧 DHI 包。

Q：UE5控制器同步打不开？
A：该功能要读本机 MeshToMetahuman 工程里的脚本；没有该工程会提示找不到文件。这不影响导出到 Max。
